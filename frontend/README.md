# KelanaAI — frontend

Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4.

Setup, environment variables, and deployment are documented once for the whole
project in the [root README](../README.md). The short version:

```bash
npm install
cp .env.example .env.local   # NEXT_PUBLIC_API_URL, NEXT_PUBLIC_MAP_TILE_URL
npm run dev                  # http://localhost:3000
```

The backend must be running separately (see [`../backend/`](../backend/)), or
every request fails with a connection error.

```bash
npm run build
npm run lint
npm test
npx tsc --noEmit
```

Note [`AGENTS.md`](AGENTS.md): this Next.js version has breaking changes versus
older conventions, and it is regenerated by `next dev`.
